Key Concepts

1. Web Browser

Client side software application that retrieves HTML, CSS, and Javascript from web servers to show the user interactive websites.

2. Chromium

The most versatile and robust browser engine developed by Google used by most modern web browsers.

3. Nexus, Netscape, Mosaic

The very first web browsers which set the precedent for modern browsers.

4. W3C

The rules/standards the web follows to make browsing the most internationally accessible.

5. HTML, CSS, JavaScript

Every technology browsers request and retrieve from web servers in order to compile them into a website.

6. Artificial Intelligence

Identify that AI is the current and future prospect of web browsing.
